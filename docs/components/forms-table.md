# FormsTable

::: tip Storybook
Browse the props, controls and all the stories of `FormsTable` in [Storybook](storybook:/docs/organisms-table-forms-formstable--docs).
:::

The [FormsTable](storybook:organisms-table-forms-formstable--sandbox) component can be used to render a
list of forms with buttons to edit, view, delete, etc on each row.

## Props

| Name   | Type           | Default | Description                                 |
|--------|----------------|---------|---------------------------------------------|
| `data` | array of forms | []      | A list of forms to be rendered in the grid. |
