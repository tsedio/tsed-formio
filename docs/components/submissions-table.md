# SubmissionsTable

::: tip Storybook
Browse the props, controls and all the stories of `SubmissionsTable` in [Storybook](storybook:/docs/organisms-table-submissions-submissionstable--docs).
:::

The submission grid will render a list of submissions and allow clicking on one row to select it.

## Props

| Name   | Type                 | Default | Description                                                                      |
|--------|----------------------|---------|----------------------------------------------------------------------------------|
| `data` | array of submissions | []      | A list of submissions to be rendered in the grid.                                |
| `form` | object               | {}      | The form definition for the submissions. This is used to render the submissions. |
