# FormViews

::: tip Storybook
Browse the props, controls and all the stories of `FormViews` in [Storybook](storybook:/docs/organisms-views-formviews--docs).
:::

The Form Views is the complete view to manage Formio form (edit, settings, access, exports) and its submissions.
This is the most advanced component of this library and the nearest implementation of the official Formio.js version.

With this component, you'll be able to build your own Form.io form builder and submission manager.
