export const shades = (name) =>
  Object.fromEntries(Object.keys(themeColors[name]).map((key) => [key, `var(--color-${name}${key === "DEFAULT" ? "" : `-${key}`})`]));

# Tailwind theme

The theme is declared with CSS variables in `@tsed/tailwind-formio/theme.css` (Tailwind CSS v4 `@theme`).
Override any of them in your own `@theme` block:

```css
@import "tailwindcss";
@import "@tsed/tailwind-formio/theme.css";

@theme {
  --color-primary: hsla(260, 80%, 45%, 1);
  --color-primary-600: hsla(260, 80%, 45%, 1);
}
```

## Colors

<ColorPalette>

The default Tailwind palette (`gray`, `blue`, `red`, `green`…) is also available. `theme.css` keeps its Tailwind CSS v3
hex values, so the templates render as they did with Tailwind CSS v3.
